Step 1: Investigation
- 1.0 Greet the user and inform them that you will look into the issue and get back to them as soon as possible (Screenshot)
  
- 1.1: Ask probing questions (Screenshot)
- - When did it start?
  - Is it affecting others?
  - - this checks the scope of the issue, and lets you know if you should troubleshoot the user's device, the network, or the central service
  - Did anything change before it started happening?

    - Verify the problem
    - - Reproduce the issue (Screenshot)
    - Gather information
    - - Start collecting logs, screenshots, and test results (screenshot event log and error code)
